# Medify247 - Comprehensive Healthcare Management Platform

Medify247 is a digital healthcare management ecosystem connecting Patients, Doctors, Hospitals, Diagnostic Centers, and Super Administrators in one platform.

## 📖 Comprehensive Documentation

For a detailed analysis of the architecture, features, database models, user roles, and API routes, please refer to the **[PROJECT_OVERVIEW.md](./PROJECT_OVERVIEW.md)**.

## ⚡ Quick Start

### 1. Backend Service
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Web Application
```bash
cd frontend
npm install
npm run dev
```

## 🌟 Key Features At A Glance
* **Smart Serial Booking Engine**: Automated even/odd serial allocation separating online bookings from offline walk-ins.
* **Multi-Association Doctors**: Unified doctor portal managing appointments across multiple hospital chambers & diagnostic centers.
* **Diagnostic Test & Digital Lab Reports**: Test catalog, serial slot reservations, and Cloudinary-powered digital lab report distribution.
* **Home Healthcare Dispatch**: Home nursing, sample collection, and home doctor visits dispatch system.
* **Super Admin Verification Workflow**: Facility verification pipeline ensuring valid trade licenses and credentials.
